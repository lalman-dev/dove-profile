# Dove Aien — Professional Profile

**Live site:** [dove-aien.vercel.app](https://dove-aien.vercel.app)

A personal branding website built for a client, designed to help her stand out in the UAE job market for retail, customer service, and front-of-house reception roles.

## About This Project

This project was developed for **Dove Aien Alinsasaguin**, a retail sales and customer service professional based in the UAE, currently seeking opportunities in Sales, Reception, Cashier, and Hospitality roles.

She engaged me to design, build, and maintain her professional online profile — including her portfolio website, CV, and supporting job-search materials — and has authorized this project to be showcased publicly as part of my own development portfolio.

## Features

- Responsive, single-page professional profile built with Next.js
- Animated sections (hero, about, experience, skills, strengths) using Framer Motion
- Downloadable CV (PDF)
- Direct WhatsApp and LinkedIn contact integration
- SEO-optimized metadata for discoverability
- Clean, warm, minimal design tailored to a hospitality/customer-service brand identity

## Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **Icons:** Lucide React, React Icons
- **Deployment:** Vercel

## Project Structure

```
src/
├── app/            # Next.js app router, layout & metadata
├── components/     # Section components (hero, about, experience, etc.)
├── data/           # Centralized profile content (profile.ts)
├── assets/         # Profile image
└── lib/            # Shared animation variants
```

## Getting Started

```bash
git clone https://github.com/lalman-dev/dove-profile.git
cd dove-profile
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Client Note

All content on this site — work history, skills, and contact details — was provided directly by the client and reflects her real professional background. This repository and the live deployment are shared publicly with her consent, as part of her active job search.
